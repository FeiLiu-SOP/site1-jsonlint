# JSON Lint Online

Free **browser-only** JSON linter and formatter. Validates syntax and pretty-prints JSON locally — no upload, no signup.

## Live

- **Tool:** https://site1-jsonlint.pages.dev/
- **Guides (GSC-aligned):**
  - [JSONLint](https://site1-jsonlint.pages.dev/jsonlint.html)
  - [Lint JSON](https://site1-jsonlint.pages.dev/lint-json.html)
  - [JSON lint online](https://site1-jsonlint.pages.dev/json-lint-online.html)

## Features

- Validate JSON syntax (line-level errors)
- Pretty-print / format
- Example payloads (valid, invalid, nested)
- Download formatted JSON
- 100% client-side — data never sent to a server

## Stack

Static HTML + CSS + vanilla JS · Cloudflare Pages
