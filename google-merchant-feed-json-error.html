Google Merchant Center JSON Feed Error — How to Fix It

Merchant Center rejects your JSON product feed?

Most “JSON feed error” / syntax failures are a trailing comma, smart quotes in a title, or an unclosed { / [. Paste the feed into a browser fixer, repair the flagged line, then upload again in Google Merchant Center.

This page is for JSON syntax problems in product feeds. It does not cover account suspension, policy disapprovals, or shipping/tax attribute rules that pass JSON but still fail Merchant review.

Common Google Merchant Center JSON feed errors

  • Invalid JSON / parse error — trailing comma after the last product or field
  • Unexpected token — curly/smart quotes in title or description
  • Unclosed bracket — missing } or ] in the products array
  • Not JSON — file is CSV/XML/HTML error page while the feed type is set to JSON
  • LLM-built feed — ChatGPT/Claude added markdown fences or a trailing comma

Fix in 3 steps

  1. Download or copy the JSON feed Merchant Center rejected (or the file you were about to upload).
  2. Paste into the product feed fixer → Validate → note the line → repair commas, quotes, and brackets.
  3. Save the valid JSON and re-upload / re-fetch the feed in Google Merchant Center.

FAQ

What does a Google Merchant Center JSON feed error usually mean?
The file is not valid JSON, so Google cannot parse products. Fix syntax first (commas, quotes, brackets), then re-upload. Attribute or policy issues are a separate step after the feed parses.
Can a trailing comma break my Merchant feed?
Yes. JSON does not allow a comma after the last item in an object or array. LLM exports and hand-edited catalogs often leave one in — remove it or use the fixer, then upload again.
Is it safe to paste my product feed into this tool?
Validation and repair run entirely in your browser; we do not upload your catalog. Still avoid pasting live API secrets — redact tokens if they appear in the file.
JSON is valid but Merchant still rejects items — why?
Valid JSON only means the file parses. Missing required attributes, bad links, or policy flags are Merchant content rules, not JSON syntax. Fix syntax here first, then use Merchant’s item issues report.
