WooCommerce Product Feed JSON Invalid — How to Fix It

WooCommerce product feed JSON invalid or won't parse?

Most failures are syntax: a trailing comma after the last product, curly quotes in name / description, or an unclosed [ in a variations array. Paste the export or REST payload into a browser fixer, repair the flagged line, then re-upload or re-sync your feed plugin.

Boundary: This page covers JSON that won't parse. Missing Woo attributes, wrong GTIN mapping, or Google Listings & Ads policy rejects after the file is valid JSON are separate catalog issues.

Where WooCommerce JSON feeds break

Woo shops often export products as CSV/XML for classic Shopping plugins, but JSON shows up in REST API dumps, custom feed apps, LLM-built import files, and some middleware that pushes Woo catalog data to Google or Meta as JSON. The parser does not care which plugin wrote the file — if the JSON is illegal, sync stops before attribute mapping starts.

Common WooCommerce product feed JSON errors

  • Invalid JSON / parse error — trailing comma after the last SKU or variation
  • Unexpected token — smart quotes pasted from Excel, Docs, or ChatGPT into titles
  • Unclosed bracket — broken variations or images arrays
  • Markdown fences — LLM wrapped the payload in ```json blocks
  • Wrong envelope — single product object where the connector expects an array (or the reverse)

Fix in 3 steps

  1. Copy the rejected JSON from the feed plugin log, export file, or Woo REST response.
  2. Paste into the product feed fixer → Validate → fix commas, quotes, and brackets on the reported line.
  3. Save the valid JSON and re-run the Woo → Google / Meta / marketplace sync.

FAQ

What does "WooCommerce product feed JSON invalid" usually mean?
The connector cannot parse the file as JSON. Fix syntax first, then re-sync. Required Woo fields (SKU, price, stock) are checked only after the document parses.
My feed plugin uses CSV — do I still need this?
Only when the pipeline or middleware uses JSON (API export, custom script, or a JSON destination). Pure CSV feeds need a CSV tool, not a JSON fixer.
Valid JSON but Google / Meta still rejects products?
Syntax is fixed; row-level issues remain (bad image URL, currency, missing id). See Google Merchant JSON feed error and Meta catalog feed JSON error for platform-specific notes.
Is it safe to paste Woo product JSON here?
Validation runs in your browser; we do not upload your catalog. Redact API keys or customer PII if they appear in the payload.
